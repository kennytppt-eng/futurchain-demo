Benefits & Challenges

Blockchain has strong advantages, but it also has issues that need to be considered before it is used in real systems.

Balanced evaluation

Blockchain can be useful when transparency and shared records are important. However, it should not be used just because it is popular. Developers still need to think about cost, speed, privacy and whether users will understand how to use it.

Benefit: Trust

Users can check records, which can improve confidence in the data.

Benefit: Security

Blockchain uses cryptography to help protect transactions and stored records.

Challenge: Energy

Some blockchains can use a lot of energy, depending on how they are designed.
